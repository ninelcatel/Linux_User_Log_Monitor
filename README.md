# Simple bash script for an university project
This script is made in bash and it's purpose is to monitor logged in and out users from a Linux system.
```
git clone https://github.com/ninelcatel/Linux_User_Log_Monitor.git
```
```
cd Linux_User_Log_Monitor
```
```
sudo chmod +x userfs.sh && ./userfs.sh [hours to execute, 1 hour implicit]
```
